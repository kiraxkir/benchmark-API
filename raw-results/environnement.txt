Images Docker

Écarts par rapport à CLAUDE.md (et pourquoi)
- MySQL : service compose « mysql », conteneur « mysql-dev », port hôte 3307. Les API joignent
  MySQL par le réseau Docker (mysql:3306).
- MySQL lancé avec --default-time-zone=+00:00 et utf8mb4 explicites pour que le suffixe « Z »
  des dates soit exact.
- reset.sql remet aussi les AUTO_INCREMENT à leur valeur initiale (identifiants reproductibles
  d'un essai à l'autre).
- schema.sql : InnoDB crée automatiquement un index sur comments.user_id (exigé par la FK).
